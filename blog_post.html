Reinforcement Learning for Crystal Relaxation

By jmedina9 • 5 min read • RL Environments

Finding the stable state of a crystal—a process known as relaxation—is the bedrock of modern materials science. But it’s also a massive computational bottleneck. Today, I'm introducing a new Reinforcement Learning environment designed to teach agents how to find energy minima autonomously.

The Challenge: The Energy Landscape

In a typical relaxation task, we adjust atomic coordinates until the forces reach zero. Traditional methods like are precise but slow. By framing this as a Markov Decision Process (MDP), we can train agents to navigate these complex potential energy surfaces (PES) with much higher efficiency.

Environment Highlights:

  • State Space: 3D coordinates and lattice parameters from the Materials Project.
  • Action Space: Atomic displacements and lattice strain tensors.
  • Reward: Energy reduction verified by the Prime Intellect verifiers library.

The Dataset

The training environment uses a carefully curated subset of the Materials Project mp-20 dataset. To ensure the agent focuses on stable materials, I filtered the collection to include only structures with an original formation energy below 0.1 eV/atom. This subset provides a challenging yet realistic set of crystal structures for the agent to learn from. https://github.com/microsoft/mattergen/tree/main/data-release

🔮 The Model: Fine-tuned CHGNet

At the heart of this environment is CHGNet (Crystal Hamiltonian Graph Neural Network), a universal machine learning potential pretrained on the Materials Project database. CHGNet predicts energies, forces, and stresses for any atomic configuration—making it ideal for rapid energy evaluations during RL training.

To improve accuracy on my specific dataset, I fine-tuned the pretrained CHGNet model using the following setup:

Fine-tuning Configuration:

  • Training samples: 2000 structures from the filtered mp-20 subset
  • Targets: Formation energy per atom + atomic forces
  • Batch size: 8
  • Epochs: 10
  • Optimizer: Adam with learning rate 1e-2
  • Loss function: Mean Squared Error (MSE)
  • Scheduler: Cosine annealing learning rate
  • Train/Val/Test split: 90% / 5% / 5%

This fine-tuning process allows the model to better capture the energy landscape of thermodynamically stable materials, providing more accurate reward signals for the RL agent during training.

1. Configuration & Imports

from datasets import Dataset
from pymatgen.core import Structure
from pymatgen.ext.matproj import MPRester
from chgnet.data.dataset import StructureData, get_train_val_test_loader
from chgnet.model import CHGNet
from chgnet.trainer import Trainer

# Configuration
MP_API_KEY = os.getenv("MP_API_KEY")
DATASET_PATH = "mp_20.json"
N_TRAIN_SAMPLES = 2000 # Real challenge (use 500 for medium)
BATCH_SIZE = 8
EPOCHS = 10 # Real challenge (use 5 for medium)
LEARNING_RATE = 1e-2

2. Data Preparation

# Load dataset and sample
dataset = Dataset.from_json(DATASET_PATH)
subset = dataset.select(np.random.choice(len(dataset), N_TRAIN_SAMPLES, replace=False))

structures, energies_per_atom, forces = [], [], []
base_model = CHGNet.load()  # Load pretrained model

# Fetch structures and prepare training data
for data in tqdm(subset, desc="Preparing data"):
    structure = get_structure_from_mp_id(data["id"])
    if isinstance(structure, Structure):
        structures.append(structure)
        energies_per_atom.append(data["formation_energy_per_atom"])
        forces.append(base_model.predict_structure(structure)["f"])

3. Create DataLoaders

chgnet_dataset = StructureData(
    structures=structures,
    energies=energies_per_atom,
    forces=forces,
)
train_loader, val_loader, test_loader = get_train_val_test_loader(
    chgnet_dataset, 
    batch_size=BATCH_SIZE, 
    train_ratio=0.9, 
    val_ratio=0.05
)

4. Fine-tune the Model

trainer = Trainer(
    model=base_model,
    targets="ef",  # energy + forces
    optimizer="Adam",
    scheduler="CosLR",
    criterion="MSE",
    epochs=EPOCHS,
    learning_rate=LEARNING_RATE,
    use_device="cpu",
    print_freq=6,
)

trainer.train(train_loader, val_loader, test_loader)
fine_tuned_model = trainer.model

# Save the fine-tuned model
torch.save(trainer.best_model.state_dict(), "fine_tuned_chgnet_model.pth")

5. Evaluation

# Evaluate on test set

    if isinstance(structure, Structure):
        y_true.append(data["formation_energy_per_atom"])

The RL Environment: Multi-Turn Crystal Relaxation

The crystal relaxation task is framed as a MultiTurnEnv—a multi-step reinforcement learning environment where the agent iteratively refines a disordered crystal structure to minimize its energy and achieve a stable configuration.

🎯 Objective

Given a disordered initial structure, the agent must generate a valid CIF file that:

  • Has valid crystallographic format
  • Matches the target composition
  • Achieves formation energy below 0.1 eV/atom
  • Minimizes atomic forces (well-relaxed)
  • Maintains physically reasonable bond lengths

How It Works

1️⃣
Initial State: The environment provides a disordered crystal structure from the MP20 dataset with high formation energy.
2️⃣
Agent Action: The LLM agent generates a response containing:
  • Reasoning about structural improvements (in <|think_start|>...<|think_end|>)
  • A proposed CIF structure (in <|answer_start|>...<|answer_end|>)
3️⃣
Evaluation: CHGNet evaluates the proposed structure across multiple rubrics, computing energies, forces, and bond lengths.
4️⃣
Feedback: The environment provides detailed feedback on what passed/failed, guiding the agent toward better structures in subsequent turns.

Reward Structure

The total reward is a weighted sum of individual rubric scores:

Rubric Weight Criteria
Format 0.10 Valid CIF syntax
Composition 0.15 Matches target formula
Formation Energy 0.60 < 0.1 eV/atom
Forces 0.24 Low atomic forces
Bond Lengths 0.15 Physically reasonable

Note: Formation energy has the highest weight (60%) as it's the primary indicator of structural stability.

📄 Format Rubric (Weight: 0.10)

Ensures the agent produces syntactically valid CIF files and properly uses the answer tags.

What It Checks:

  • CIF string is present between <|answer_start|> and <|answer_end|> tags
  • CIF can be parsed by pymatgen's CifParser
  • Structure contains valid crystallographic data
  • No critical syntax errors in the CIF format

Scoring:

if CIF successfully parsed:
    reward = 1.0 * weight (0.10)
else:
    reward = 0.0

Why it matters: Without a valid CIF, the structure cannot be evaluated by CHGNet. This rubric ensures the agent learns the proper format before focusing on energy optimization.

⚗️ Composition Rubric (Weight: 0.15)

Verifies that the generated structure has the correct chemical composition in the right ratios.

What It Checks:

  • Composition matches the target formula (e.g., NaCl, Li₂O)
  • Element ratios are correct (reduced composition)
  • No extra or missing elements

Implementation:

# Uses pymatgen's ElementComparator
cif_composition = structure.composition.reduced_composition
target_composition = Composition(target_formula).reduced_composition

if ElementComparator().are_equal(cif_composition, target_composition):
    reward = 1.0 * weight (0.15)
else:
    reward = 0.0

Why it matters: The chemical composition fundamentally determines material properties. An agent that generates NaCl₂ instead of NaCl has failed at a basic chemistry level.

⚡ Formation Energy Rubric (Weight: 0.60)

The most important rubric—evaluates thermodynamic stability through formation energy.

What It Checks:

  • Formation energy per atom < 0.1 eV/atom (threshold)
  • Calculated using fine-tuned CHGNet model
  • Lower energy = more stable structure = higher reward

Available Reward Strategies

The environment supports three different reward functions to guide the optimization process:

1. Discrete Reward (Step Function)

Binary feedback. Simple but provides sparse gradients.

def formation_energy_discrete(..., threshold=0.1):
    if energy <= threshold:
        return 1.0
    return 0.0
2. Linear Reward (Default)
Recommended

Continuous feedback. Decays linearly as energy rises above threshold.

def formation_energy_linear(..., threshold=0.1, max_penalty=2.0):
    if energy <= threshold:
        return 1.0
    elif energy >= threshold + max_penalty:
        return 0.0
    else:
        # Interpolate 1.0 -> 0.0
        return 1.0 - (energy - threshold) / max_penalty
3. Exponential Reward

Aggressive penalty for high energy structures.

def formation_energy_exponential(..., threshold=0.1, scale=1.0):
    if energy <= threshold:
        return 1.0
    excess = energy - threshold
    return np.exp(-excess / scale)

⚠️ Critical Threshold

Structures with formation energy above 0.1 eV/atom are considered thermodynamically unstable and unlikely to exist naturally. The agent must learn to minimize this value through proper atomic positioning and lattice parameters.

Why it matters: Formation energy is the gold standard for predicting whether a material can be synthesized. This 60% weight ensures the agent prioritizes structural stability above all else.

🔧 Forces Rubric (Weight: 0.24)

Measures how well-relaxed the structure is by examining forces on individual atoms.

What It Checks:

  • Maximum force on any atom < threshold (typically 0.5 eV/Å)
  • Average force magnitude across all atoms
  • Indicates if atoms are in equilibrium positions

Available Reward Strategies

The environment provides three ways to reward structural relaxation:

1. Discrete Reward

Strict binary check. Only rewards if the maximum force on any atom is below threshold.

def forces_discrete(..., threshold=0.05):
    # forces = get_forces(structure)
    max_force = np.max(np.linalg.norm(forces, axis=1))
    return 1.0 if max_force <= threshold else 0.0
2. Continuous Decay (Default)
Recommended

Smoothly penalizes larger forces. Even imperfect structures get some credit, guiding the gradient.

def forces_continuous_decay(..., decay=1.0):
    # forces = get_forces(structure)
    max_force = np.max(np.linalg.norm(forces, axis=1))
    return 1.0 / (1.0 + (decay * max_force))
3. Continuous Ratio

Rewards the percentage of well-behaved atoms. Good for large structures.

def forces_continuous_ratio(..., threshold=0.05):
    # forces = get_forces(structure)
    force_norms = np.linalg.norm(forces, axis=1)
    good_forces = np.sum(force_norms <= threshold)
    return good_forces / len(force_norms)

Physical intuition: In a stable structure, atoms sit at energy minima where forces are near zero. Large forces indicate atoms "want" to move—the structure hasn't truly relaxed.

💡 Agent learning: This rubric teaches the agent that low formation energy alone isn't enough—the structure must also be mechanically stable with minimal residual forces.

📏 Bond Lengths Rubric (Weight: 0.15)

Validates that interatomic distances are chemically reasonable based on atomic radii and bond types.

What It Checks:

  • Bond lengths fall within expected ranges (±32% tolerance)
  • Accounts for ionic vs covalent bonding (electronegativity difference)
  • Special handling for hydrogen bonds (more flexible)
  • Uses pymatgen's CrystalNN to identify bonded atoms

Available Reward Strategies

You can configure the strictness of the bond length check:

1. Discrete Reward

Binary accept/reject. Only rewards structures where the global bond score exceeds a threshold.

def bond_lengths_discrete(..., threshold=0.75):
    # score = bond_length_reasonableness_score(structure)
    if not score or score < 0:
        return 0.0
    return 1.0 if score >= threshold else 0.0
2. Continuous Reward (Default)
Recommended

Returns the raw reasonableness score (0.0 to 1.0), encouraging incremental improvements.

def bond_lengths_continuous(..., **kwargs):
    # score = bond_length_reasonableness_score(structure)
    if not score or score < 0:
        return 0.0
    # Returns raw score 0.0 - 1.0
    return max(0.0, min(1.0, score))

Common Failures:

  • Atoms too close → unphysical overlap
  • Atoms too far → weak/nonexistent bonding
  • Incorrect lattice parameters → compressed/expanded structure

Why it matters: Even if CHGNet predicts low energy, physically impossible bond lengths indicate the structure is chemically unrealistic. This rubric acts as a sanity check on the agent's geometric proposals.

Training Runs: How an LLM "Learns" Physics

Posted on February 17, 2026 • Tagged: RL Materials Science

I’ve spent the last week parsing the logs from the latest GRPO training run (run_id: wwre3g...), and the results are honestly proving to interesting, with some evidence of a "cognitive shift."

Over the course of 100 training steps, the model didn't just get "better" at the reward function. It went from checking arithmetic to a "confident computational" scientist running simulations.

1. The Cognitive Shift: From Calculator to Simulator

The first finding is the inversion of explicit vs. implicit knowledge. In the early steps (Step 0–20), the model is obsessed with the mechanics of the file format. It writes paragraphs justifying why it changed a coordinate from -0.1 to 0.9 (wrapping the boundary).

By Step 80 (peak performance), it stops talking about the math entirely. Instead, it starts hallucinating a "methodology." It claims to be running VASP calculations, checking force convergence thresholds (e.g., "forces < 0.01 eV/Å"), and applying PBE functional corrections.

The "Bond" Paradox

I tracked keyword frequency across the run. The word "bond" appears ~2.0 times per sample in Step 0. By Step 80, it drops to 0.0.

You might think this means the model stopped caring about bonding. In reality, the Bond Length Reward metric spiked from 0.57 to 0.80 in the same period. The model internalized the physics so deeply it no longer needed to "show its work."

2. The "Refinement" Strategy

Early in the run, the model treated the input crystals as "wrong," aggressively resizing the lattice by an average of 0.051 Å per step. This often broke the symmetry and tanked the reward.

By Step 80, the model learned a crucial lesson in materials science: Nature prefers local minima. It switched to a micro-optimization strategy, reducing the lattice modification to just 0.006 Å (an 88% reduction). It learned that the secret to high rewards wasn't reconstruction, but subtle relaxation.

3. The Failure Mode: The "Retry" Illusion

Here is the kicker, and probably the biggest headache for my defense: The model does not learn through iteration.

I analyzed 37 cases where the first attempt failed (Energy > 0.1 eV/atom).

  • Physical Recoveries: 0. (Not a single case of fixing bad physics).
  • Syntax Recoveries: 7. (Fixing missing lines in the CIF file).

When the model receives negative feedback like "Formation energy is too high," it doesn't know how to calculate a gradient from that text. It treats the second turn as a "re-roll" of the dice, repeating the same logic and hoping for a better random seed. It has learned State Recognition (what a good crystal looks like) but not Gradient Descent (how to fix a bad one).

4. The Silver Lining: In-Context Calibration

However, there is one area where two turns helped: Prediction. Even though the model couldn't fix the structure, its ability to predict the formation energy improved significantly in the second turn.

This suggests an "Actor-Critic" disconnect. The model can use the ground truth from the first turn to calibrate its internal "zero point" (Critic success), even if it lacks the policy to manipulate the atoms to reach that state (Actor failure).

"The model learns to measure the problem before it learns to fix it."

Next Steps:

The data implies that simply telling the model "Energy is too high" is useless. I need to implement vector feedback—telling the model exactly which bond is strained—if I want to see true iterative improvement. Back to the cluster.
